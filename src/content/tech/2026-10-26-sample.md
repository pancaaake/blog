技術記事では、用語集に登録したプログラミング用語に自動で説明が付きます。
コードブロックとインラインコード（`API`）の中は変換されません。

```ts
// Node.js から API を呼ぶ例
const res = await fetch('https://example.com/api');
console.log(await res.json());
```

Node.js と C++ の比較。APIs や C++17 のような書き方でも、英字の途中では反応しません。
